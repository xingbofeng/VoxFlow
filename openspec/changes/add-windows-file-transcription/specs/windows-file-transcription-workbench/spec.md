## ADDED Requirements

### Requirement: macOS 文件转写页视觉与交互对齐
Windows MUST 新增文件转写导航路由和页面，其视觉与当前 macOS `FileTranscriptionView` 对齐：顶部标题/副标题/浏览入口、格式提示拖放区、左侧队列、右侧结果详情、状态栏、任务卡、按钮层级、圆角、间距、空态、运行态、失败态、部分失败态、浅色/深色主题和禁用规则均以 macOS 当前可见行为为基线。不得使用默认 WPF 控件样式替代已定义的主题 token。

#### Scenario: 以基准尺寸打开页面
- **WHEN** 用户在 1260×720、100% 缩放下打开文件转写路由
- **THEN** Windows 页面呈现与 macOS 对应页面相同的信息层级、左右栏关系、卡片密度、标题层级、操作位置和空态，不出现截图/OCR/笔记/Agent 占位入口

#### Scenario: 深色主题与高 DPI
- **WHEN** 用户切换应用内深色主题或在 125/150/200% DPI 下打开页面
- **THEN** 页面沿用 Windows V1 的主题和缩放规则，文字、卡片、队列和结果栏不重叠、不裁剪且与 macOS 同状态视觉语义一致

### Requirement: 队列与详情操作
页面 MUST 显示每个任务的文件名、格式、时长、Provider 模式、分段数量、状态、进度和可用操作。queued 任务提供启动；running 任务提供取消；interrupted/partiallyFailed 任务提供继续和从头重试；所有任务提供删除；完成或部分完成任务提供播放、复制、导出和全文翻译。删除运行任务前必须提供与 macOS 相同语义的确认。

#### Scenario: 运行任务的可见进度
- **WHEN** 当前任务正在处理第 2/5 段
- **THEN** 队列卡、详情与底部状态栏均显示一致的 2/5 与进度，其他 queued 任务不可被误显示为 running

#### Scenario: 部分失败详情
- **WHEN** 任务完成但其中一段失败
- **THEN** 页面显示部分失败状态、已完成文本、失败段摘要和继续/从头重试入口；复制与导出已完成文本仍可用

### Requirement: 分段诊断与结果呈现
页面 MUST 提供可折叠的高级诊断，显示持久化的段索引、时间范围、状态、重试次数、Provider 模式、fallback 类别和脱敏错误。结果区必须支持原文选择、翻译后原文/译文对比，以及与 macOS 相同语义的空结果和处理反馈。

#### Scenario: 展开高级诊断
- **WHEN** 用户在完成或部分失败任务中展开高级诊断
- **THEN** 系统按段索引顺序显示持久化记录，且不会显示原始音频、API Key、Authorization、完整 Provider 请求或敏感诊断内容

### Requirement: 完整本地化与无障碍语义
页面 MUST 将其所有状态、按钮、确认、格式提示、错误和诊断摘要使用 Windows 资源并同步 en、zh-Hans、zh-Hant、ja、ko。控件必须具有可访问名称、键盘焦点顺序和禁用原因，且本地化缺失不得回退为资源 key。

#### Scenario: 切换界面语言
- **WHEN** 用户切换 Windows 应用界面语言并重新进入文件转写页
- **THEN** 页面导航、标题、按钮、状态、错误和导出格式名称均显示为目标语言的自然文案，所有五种资源具有相同参数占位符语义
