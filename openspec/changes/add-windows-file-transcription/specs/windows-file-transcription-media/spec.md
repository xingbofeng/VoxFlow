## ADDED Requirements

### Requirement: 受控 FFmpeg 运行时与供应链校验
系统 MUST 仅使用安装包内固定目录的 x64 FFmpeg/ffprobe 运行时。运行前必须校验版本、文件大小和 SHA-256；安装器必须随包提供对应 LGPL 许可证、版权 notice 和来源记录。系统不得解析用户 PATH、自动下载可执行文件、调用 Python/WSL/CUDA，或把 FFmpeg 作为常驻服务运行。

#### Scenario: 已验证运行时开始媒体准备
- **WHEN** 用户启动有效文件任务且安装包中的 FFmpeg 清单匹配
- **THEN** 系统从应用 runtime 目录启动受控进程，并在诊断中只记录版本和脱敏结果

#### Scenario: 运行时损坏或缺失
- **WHEN** FFmpeg 文件缺失、哈希不匹配或架构不是 x64
- **THEN** 任务在访问 Provider 前失败并提示修复/重装，系统不回退到 PATH、网络下载或其他解码器

### Requirement: 音视频准备与分段媒体契约
系统 MUST 使用 ffprobe 验证首条可读音轨和时长，并用 FFmpeg 将源文件准备为临时 16 kHz、单声道 PCM WAV。每个转写窗口必须是 30,000 ms，下一窗口起点为前一窗口起点加 28,500 ms，且窗口末尾包含 1,500 ms 重叠；Provider 只接收由此产生的统一 PCM 输入。

#### Scenario: 导入含音轨的视频
- **WHEN** 用户导入一份含音轨的 MP4 或 MOV
- **THEN** 系统提取音轨、显示正确总时长，并按统一 PCM 窗口处理，而不是把视频字节直接传给 Provider

#### Scenario: 导入没有音轨的视频
- **WHEN** ffprobe 未发现可读音轨
- **THEN** 系统标记任务失败并显示“未发现可转写音轨”，不创建空 Segment 或发送网络请求

### Requirement: 临时文件、磁盘空间与取消清理
系统 MUST 在任务专属临时目录创建准备文件和窗口文件，并在完成、失败、取消、删除和下次启动清理后删除它们。系统必须在准备前检查可用磁盘空间；所有 FFmpeg 子进程必须可取消，并在取消时终止整个进程树。

#### Scenario: 用户在媒体准备期间取消
- **WHEN** FFmpeg 正在解码或切出窗口时用户取消任务
- **THEN** 系统终止关联进程树、删除已创建临时文件、将任务标为 cancelled，且不得开始 Provider 会话

#### Scenario: 磁盘空间不足
- **WHEN** 可用空间不足以准备临时 PCM
- **THEN** 系统在开始解码前显示空间不足错误，源文件和已存在的任务/分段记录均不被修改

### Requirement: 与 macOS 一致的音频播放操作
系统 MUST 在任务详情中提供播放/暂停源媒体的操作，并对音频和视频文件使用同一受控媒体准备路径。播放失败不得影响转写、翻译、导出或分段状态。

#### Scenario: 播放已完成视频任务
- **WHEN** 用户在已完成 MP4 任务中点击播放
- **THEN** 系统播放其准备后的音频，并在再次点击时暂停；播放状态只影响该任务详情的播放控件
