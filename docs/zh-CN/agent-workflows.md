# Agent 工作流

码上写有两类 Agent 工作流：给 AI 工具生成提示词，以及把语音指令投递给本地 coding-agent 会话。

## Agent Compose / 任务助手

任务助手读取当前窗口可见文本和可选 OCR 上下文，结合你的口述意图，生成一段可贴给 ChatGPT、Claude、Codex、Cursor 或其他 LLM 工具的提示词。

安全边界：

- 结果只复制。
- 不自动注入到其他 App。
- 不按 Enter。
- 不自动发送消息。

这让任务助手仍然接近“语音键盘”：帮你写出更好的提示词，但不替你控制目标 App。

## AI Coding 助手控制台

AI Coding 助手面向本地终端 Agent。它可以配合已注册的 Codex、Claude、CodeBuddy 或其他 terminal-agent 会话工作。

典型流程：

1. 启动或注册本地 Agent 会话。
2. 说出目标名称和任务。
3. 码上写解析目标会话。
4. 目标模糊或首次学习别名时请求确认。
5. 指令投递给已注册会话。
6. 工作台里可查看调度历史和 trace。

## Runtime 接管

当本地 agent runtime 可用时，码上写可以让 runtime 直接处理请求。此时任务应该记录为“由 runtime 完成”，而不是普通文本输出取消。这个区别会影响日志、任务历史和未来统计。

## 安全规则

- 只投递到已注册会话。
- 目标名称模糊时确认。
- 别名学习需要用户确认。
- 删除文件、修改文件、执行命令等高风险指令应提高确认等级。
- 调度历史限制大小并保存在本地。

## 当前边界

- 任务助手只复制。
- AI Coding 助手投递到本地会话。
- 码上写不会在注册 Agent 会话之外静默执行 shell 命令。
- runtime trace 默认本地保存，除非用户启用外部诊断。
